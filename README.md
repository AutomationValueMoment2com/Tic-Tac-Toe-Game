🎮 Tic Tac Toe Game (Python Tkinter)

A simple and fun Tic Tac Toe game built using Python’s tkinter library. This project is beginner-friendly and demonstrates how to create a graphical user interface (GUI) along with basic game logic.

✨ Features

Two-player game (😊 vs 👿)

Interactive GUI using Tkinter

Automatic win and draw detection

Reset button to start a new game

Simple and clean design

🧠 How It Works

The game board is a 3x3 grid.

Players take turns clicking on the buttons.

Each click places their symbol (😊 or 👿).

The program checks for:

Winning combinations

Draw condition (when all cells are filled)

A popup message announces the result.

▶️ How to Run

Make sure you have Python installed (Python 3 recommended).

Save the code in a file, for example:

tic_tac_toe.py

Run the file:

python tic_tac_toe.py
🕹️ How to Play

Launch the game.

Player 😊 starts first.

Click on any empty box to make a move.

Players alternate turns.

The game will automatically announce:

Winner 🎉

Or Draw 🤝

Click Reset Game to play again
